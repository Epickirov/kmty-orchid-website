批量导入 Bulk import

直接上传你们平时用的 Excel（.xlsx）或 CSV，列的顺序不限——读入后逐列指定含义即可， 系统会记住这份对应关系，下次同样格式的表一键导入。也可以从 Excel 复制粘贴到下面的文本框。 每行一个批次，至少需要 编号 + 数量 + 起止周；名称、杯径、花径、株高等若已录入 品种库，表里可以完全不填。编号＋杯径＋起始周相同的批次会被覆盖，其余新增。
