批量导入 Bulk import

从 Excel 直接复制粘贴，或选择 CSV 文件。每行一个批次，列顺序： 编号, 英文名, 中文名, 杯径, 数量, 起始周, 结束周, 年份, 备注, 每盘株数, 梗数, 花径, 株高。 年份之后各列均可留空；梗数填 SS／单梗 或 DS／双梗，花径与株高以厘米计。 编号＋杯径＋起始周相同的批次会被覆盖，其余新增；两张照片请在上方逐个上传。
